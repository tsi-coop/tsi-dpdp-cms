# Integration examples

| Folder | What it is |
|---|---|
| [`scripts/`](scripts/) | API reference clients: consent and grievance lifecycle test scripts, notification listener, purge handler. |
| [`website-consent/`](website-consent/) | Standalone website consent banner with a backend proxy. See the [Website Consent Banner Integration Guide](../../docs/guides/website-consent-banner-integration-guide.md). |

Small examples of other integration patterns (see the [roadmap](../../docs/plan/integrations-roadmap.md)) get their own standalone folder here. Full product integrations (WordPress, Shopify and so on) are built by partners on the SDKs.
